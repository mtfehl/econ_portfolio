3. Pareto Optimality

3.1 The Concept

Definition: an allocation is Pareto optimal if no reallocation makes one agent better off without harming the other

Geometric interpretation: tangency of indifference curves

Figure: Edgeworth box showing two indifference curves tangent at a Pareto optimal point vs. crossing at a non-optimal point

3.2 The MRS Condition

\[\text{MRS}_A(x_1, x_2) = \text{MRS}_B(\omega_1 - x_1,; \omega_2 - x_2)\]

Derivation: why equal MRS means no mutually beneficial trade exists

The substitution: B’s utility written in A’s coordinate frame

3.3 Special Preference Cases

Normal (differentiable): smooth contract curve via MRS = MRS

Leontief / min: L-shaped curves - Pareto set is a region, not a curve

Convex / max: reverse-L curves - Pareto set is the boundary

Non-quasi-concave: bowl-shaped curves - interior tangencies are minima, not maxima; Pareto set on boundary via grid dominance

5. Competitive Equilibrium

5.1 The Walrasian Setup

Price normalization: \(p_1 = 1\), find \(p_2^*\)

Budget constraint: each agent sells their endowment at market prices, buys their preferred bundle

\[p_1 x_1 + p_2 x_2 = p_1 w_{i,1} + p_2 w_{i,2}\]

Market clearing: demand_A(p2) + demand_B(p2) = \(\omega\) (by Walras’ Law)

5.2 Deriving Demand

The utility maximization problem: Lagrangian, FOC \(\frac{MU(x_1)}{MU(x_2)} = \frac{p_1}{p_2}\), budget binding

Key engineering point: makeDemandFn() derives the formula symbolically once → returns a vectorized @(p2) function

Code block (collapsed): the demand derivation for the running example, showing the symbolic formula before vectorization

5.5 Welfare Theorems

FWT: every CE is Pareto optimal; the market doesn’t waste

SWT: any Pareto optimal allocation can be supported as a CE with lump-sum transfers; i.e., equity and efficiency can be separated

9. Limitations and Extensions

9.1 Current Limitations

Static endowment economy: no production, no capital

Two agents, two goods: Edgeworth box geometry doesn’t generalize

Price-taking assumption: agents have no market power

9.2 Natural Extensions

n-agent tâtonnement: aggregate excess demand across n agents; same update rule

Overlapping generations: agents trade across time periods

Network trade: bilateral trades along a graph instead of a centralized auctioneer
